#  William Santana — Portfolio

A modern and interactive portfolio built to showcase my work, technical skills, and experience as a Frontend Engineer.

Designed with a strong focus on performance, accessibility, responsive design, and smooth user experience.

# About

This portfolio was built from scratch using modern web technologies and best practices.

It highlights my featured projects, professional journey, technical stack, and contact information while maintaining a clean, elegant, and highly interactive interface.

# Getting Started

Clone the repository:

```bash
git clone https://github.com/wwilliamsantana/portfolio-william.git
```

Install dependencies:

```bash
cd portfolio-william
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
