# William Santana — Portfólio

Um portfólio moderno e interativo, desenvolvido para apresentar meus projetos, habilidades técnicas e experiência como Engenheiro Front-end.

Projetado com forte foco em desempenho, acessibilidade, design responsivo e uma experiência de usuário fluida.



## Demonstração ao vivo

### 🔗 [Portfólio](https://portfolio-william-nu.vercel.app/)



# Sobre

Este portfólio foi desenvolvido do zero, utilizando tecnologias web modernas e boas práticas de desenvolvimento.

Ele destaca meus principais projetos, trajetória profissional, tecnologias e informações de contato, mantendo uma interface limpa, elegante e altamente interativa.

# Como começar

Clone o repositório:

```bash
git clone https://github.com/wwilliamsantana/portfolio-william.git
```

Instale as dependências:

```bash
cd portfolio-william
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```
